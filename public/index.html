O feed “continua igual” / só vejo News?
  1. Cache do leitor: remova o feed e volte a subscrever, ou use gameinformer.xml?refresh=1 (alguns leitores ignoram o parâmetro). O GitHub Pages pode cachear o XML ~10 minutos.
  2. Ordem no site vs. no leitor: no gameinformer.com/news os três destaques no topo são News; a seguir vêm State of Play e outras secções. O XML segue essa ordem, mas muitas apps ordenam por data de publicação — notícias mais recentes (4 Jun) ficam acima de State of Play (2 Jun).
  3. Secções fora da página 1: “gamer culture” e outras etiquetas aparecem mais abaixo no site (após “Load more”); este feed inclui só a primeira página (~20 artigos).
  4. Imagens: as URLs apontam para gameinformer.com; alguns leitores bloqueiam imagens remotas ou hotlink.
